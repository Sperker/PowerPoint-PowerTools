PowerPoint Pan & Zoom Add-in - Changelog
=======================================

v1.7 - Packaging & Release Readiness Release
--------------------------------------------
This release keeps the stable v1.6 add-in behavior unchanged and improves the distribution package for easier sharing, installation and support.

Changes:
- Updated version metadata to v1.7.
- Added README_PowerPointPanZoomAddIn_v1.7.txt.
- Added INSTALL_GUIDE_PowerPointPanZoomAddIn_v1.7.txt.
- Added TROUBLESHOOTING_PowerPointPanZoomAddIn_v1.7.txt.
- Added RELEASE_CHECKLIST_PowerPointPanZoomAddIn_v1.7.txt.
- Added LICENSE_NOTICE_MaterialIcons.txt.
- Updated changelog for v1.7.
- Kept the stable v1.6 Material Icons integration unchanged.
- Kept the stable v1.5 settings functionality unchanged.
- Kept the stable pan and zoom core behavior unchanged.

v1.6 - Material Icons Release
-----------------------------
This release removes the dependency on Office built-in imageMso icons and replaces them with embedded Google Material Symbols PNG icons.

Changes:
- Updated version metadata to v1.6.
- Replaced imageMso-based ribbon icons with embedded Material icons.
- Added RibbonIconProvider.cs for loading embedded PNG resources.
- Added getImage callback support in PanZoomRibbon.cs.
- Added fallback icons if an embedded PNG cannot be found.

v1.5 - Settings Polish & Diagnostics Release
--------------------------------------------
This release improves the v1.4 Settings experience and adds lightweight diagnostics information.

Changes:
- Improved the Settings dialog layout with grouped sections.
- Improved zoom level validation.
- Added the settings file path to the About dialog.
