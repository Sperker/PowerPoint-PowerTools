PowerPoint Pan & Zoom Add-in v1.7 - Troubleshooting Guide
========================================================

Add-in is not visible in PowerPoint
-----------------------------------
1. Close PowerPoint completely.
2. Check Task Manager and end POWERPNT.EXE if still running.
3. Reopen PowerPoint.
4. Go to File > Options > Add-ins.
5. At the bottom, select COM Add-ins and click Go.
6. Check whether PowerPointPanZoomAddIn is listed and enabled.
7. Also check Disabled Items and re-enable the add-in if necessary.

Installation says another version is already installed
-----------------------------------------------------
This can happen if an older ClickOnce version was installed from a different folder.

Fix:
1. Close PowerPoint.
2. Uninstall PowerPointPanZoomAddIn from Windows Settings > Apps.
3. Run this command in cmd if needed:

rundll32 dfshim.dll CleanOnlineAppCache

4. Install v1.7 again from the full publish package.

Icons show as fallback letters
------------------------------
The embedded PNG resources are probably not included correctly.

Check in Visual Studio:
1. The project contains an Icons folder under the C# project.
2. The following files are visible under the project:
   - Icons\pan_tool.png
   - Icons\ads_click.png
   - Icons\settings.png
   - Icons\info.png
3. Each PNG file has:
   - Build Action: Embedded Resource
   - Copy to Output Directory: Do not copy

Settings do not persist
-----------------------
Check whether the settings file exists:

%APPDATA%\PowerPointPanZoomAddIn\settings.ini

If the file is missing, open Settings, save once, close PowerPoint and reopen it.

Zoom does not react
-------------------
Check:
1. Zoom to Cursor is enabled in the Add-Ins tab.
2. The mouse cursor is over the PowerPoint window.
3. Use Ctrl + Shift + MouseWheel.
4. The current zoom level is within the configured zoom range.

Pan does not react
------------------
Check:
1. Pan Mode is enabled in the Add-Ins tab.
2. Use the middle mouse button and drag.
3. Try a lower Pan threshold in Settings.
4. Try a lower or higher Pan step divisor depending on desired sensitivity.

Reset settings
--------------
Option A:
- Open Settings and click Reset defaults.

Option B:
- Close PowerPoint.
- Delete:

%APPDATA%\PowerPointPanZoomAddIn\settings.ini

- Reopen PowerPoint.
