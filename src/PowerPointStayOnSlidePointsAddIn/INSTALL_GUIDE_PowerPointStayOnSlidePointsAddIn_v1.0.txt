Installationsanleitung - PowerPoint Stay On Slide Points Add-In v1.0
====================================================================

Entwicklungs- & Debug-Modus (Visual Studio):
1. Öffne PowerPointStayOnSlidePointsAddIn.sln in Visual Studio 2022.
2. Drücke F5 (Starten) – PowerPoint startet mit dem geladenen Add-In.
3. Im Menüband unter dem Reiter "Add-Ins" erscheint die Gruppe "Stay on Slide v1.0".

ClickOnce / Veröffentlichung:
1. In Visual Studio mit der rechten Maustaste auf das Projekt klicken und "Veröffentlichen..." wählen.
2. Oder per MSBuild:
   msbuild PowerPointStayOnSlidePointsAddIn.csproj /target:Publish /p:Configuration=Release
3. Das erzeugte Setup.exe / .vsto kann per Doppelklick auf jedem Rechner installiert werden.

Manuelle Registrierung / VSTO Add-In Registrierung:
Der VSTO-Add-In-Eintrag wird in der Windows-Registrierung unter:
HKEY_CURRENT_USER\Software\Microsoft\Office\PowerPoint\Addins\PowerPointStayOnSlidePointsAddIn
abgelegt mit:
- Description: "PowerPoint Stay On Slide Points Add-In"
- FriendlyName: "PowerPointStayOnSlidePointsAddIn"
- LoadBehavior: 3 (beim Start automatisch laden)
- Manifest: Pfad zur .vsto-Datei
