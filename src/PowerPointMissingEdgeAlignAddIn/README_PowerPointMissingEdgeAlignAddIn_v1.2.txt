PowerPoint Missing Edge Align Add-In v1.2
=========================================

Überblick:
Das PowerPointMissingEdgeAlignAddIn ergänzt PowerPoint um die schmerzlich vermisste
Funktion zum exakten Aneinander-Ausrichten von Formen Kante an Kante (Edge-to-Edge).

Funktionsweise:
1. Wählen Sie die zu verschiebende Form aus (Quellform).
2. Klicken Sie im Menüband auf "EdgeAlign" (oder nutzen Sie die Schnellzugriffsleiste).
   Ein kurzer Ton signalisiert, dass der Ausrichtungs-Modus aktiv ist.
3. Klicken Sie auf die Referenzform (Zielform).
   Die Quellform wird automatisch mathematisch exakt an der nächstgelegenen Kante
   der Zielform ausgerichtet.

Pro-Tipps & Tasten-Modifikatoren:
- Strg gedrückt halten: Wendet den in den Einstellungen (Settings) konfigurierten
  Abstand (Gap in pt) zwischen den Kanten an.
- Umschalt (Shift) gedrückt halten: Schaltet die automatisch erkannte Ausrichtungsachse
  um (vertikal statt horizontal bzw. umgekehrt).

Menüband (Ribbon):
- Tab: Add-Ins
- Gruppe: Missing Edge Align v1.2
- Action-Button: EdgeAlign (Großer Button mit Google Material Symbol auto_awesome_mosaic)
- Button: Settings (Einstellungsdialog für Standardabstand)
- Button: About (Produktinfo, Versionshinweise und GitHub-Link)

Systemanforderungen:
- Microsoft Windows 10 / 11
- Microsoft PowerPoint 2016 / 2019 / 2021 / Microsoft 365 (Desktop-Version)
- .NET Framework 4.8
- Visual Studio 2010 Tools for Office Runtime (VSTO Runtime)
