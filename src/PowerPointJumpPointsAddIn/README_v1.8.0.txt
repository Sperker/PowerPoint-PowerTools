PowerPoint Jump Points Add-in v1.8.0

New in v1.8.0:
- The Jump Points Navigator now has two button rows.
- Row 1 contains Navigator shortcuts: Current Jump Point and Next Jump Point.
- Row 2 contains management actions: Go To, Rename, Delete, Delete All, Refresh, Close.
- Current Jump Point highlights the current slide in the navigator if the current slide is a jump point.
- Next Jump Point jumps to the next jump point and refreshes/highlights the navigator.

Replace/add all .cs files in this ZIP. Then run:
Build -> Clean Solution
Build -> Rebuild Solution
F5
