PowerPoint Pan & Zoom Add-in v1.8 - Installation Guide
=====================================================

Target audience
---------------
This guide is intended for users who install the PowerPoint Pan & Zoom Add-in from a ClickOnce publish package.

Prerequisites
-------------
The target computer should already have:

- Windows
- Microsoft PowerPoint Desktop
- .NET Framework 4.x / 4.8
- Visual Studio Tools for Office Runtime

Installation without admin rights
---------------------------------
1. Close PowerPoint completely.
2. Copy the full installation ZIP to a local folder.
3. If Windows shows the file as blocked:
   - Right-click the ZIP file.
   - Open Properties.
   - Select Unblock / Zulassen if visible.
4. Extract the full ZIP package.
5. Run PowerPointPanZoomAddIn.vsto.
6. If that does not start the installer, run setup.exe.
7. Confirm the installation prompts.
8. Open PowerPoint.
9. Go to the Add-Ins tab.
10. Verify that "Pan & Zoom v1.8" is visible.

Important package rule
----------------------
Do not distribute setup.exe alone. Always distribute the complete publish folder, including:

- setup.exe
- PowerPointPanZoomAddIn.vsto
- Application Files\

Update installation
-------------------
If a previous version was installed from a different folder or location, uninstall the previous version first:

1. Close PowerPoint.
2. Windows Settings > Apps > Installed Apps.
3. Search for PowerPointPanZoomAddIn.
4. Uninstall it.
5. Install v1.8 from the new package.

Uninstall
---------
1. Close PowerPoint.
2. Windows Settings > Apps > Installed Apps.
3. Search for PowerPointPanZoomAddIn.
4. Select Uninstall.

Settings after uninstall
------------------------
Per-user settings may remain under:

%APPDATA%\PowerPointPanZoomAddIn\settings.ini

Delete this folder only if you want to reset all user-specific settings.
